# 沪深双来源证券主数据合并设计

## 1. 目标

在不伪造来源、不混淆许可边界的前提下，将上交所与深交所分别发布的证券主数据组合成完整的沪深 A 股研究范围，为单日全市场行情摄取提供代码门禁。

本设计只解决证券主数据的双来源导入、校验与派生合并，不新增网络爬虫，不改变行情、财务或策略模型。

## 2. 设计原则

- 上交所与深交所原始文件分别保存、分别校验、分别版本化。
- 每个快照只能声明一个真实 `source_id`、`source_url` 和内容哈希。
- 系统不保存伪造的“合并来源文件”；全市场集合是两个有效快照的可重复计算派生结果。
- 任一来源缺失、策略失效、数据越界或代码冲突时，阻断全市场摄取，不退化成半市场候选榜。
- 只保留沪深主板、科创板和创业板人民币 A 股；排除北交所、B 股和港股。

## 3. 数据模型

保留现有 `SecurityMasterSnapshot`，每个快照代表一个官方来源。

新增只读派生类型 `SecurityMasterUniverse`：

- `components`：本次合并采用的 SSE、SZSE 快照元数据；
- `securities`：按 `ts_code` 排序的合并证券集合；
- `as_of`：两个组件中较早的采集时间，用作集合数据截止时间；
- `universe_hash`：由两个组件的来源、版本和内容哈希确定性计算；
- `quality_status`：仅在两个组件均有效且无冲突时为 `VALID`。

派生集合不覆盖或修改任何源快照。

## 4. 导入与合并流程

1. 操作员分别运行两次 `import-security-master`：
   - SSE 文件使用 `source_id=sse` 和获批的上交所 HTTPS 原文链接；
   - SZSE 文件使用 `source_id=szse` 和获批的深交所 HTTPS 原文链接。
2. 导入前继续执行现有 Policy Guard 校验：来源已批准并启用、用途包含 `security_master`、协议和 hostname 精确匹配。
3. 导入器校验每条证券与来源一致：
   - `.SH`、`exchange=SSE` 只能进入 SSE 快照；
   - `.SZ`、`exchange=SZSE` 只能进入 SZSE 快照。
4. 读取全市场集合时，系统分别选择 SSE、SZSE 各自最新的有效快照，而不是选择全表中最新的一条记录。
5. 系统重新验证两个组件的来源策略、范围和内容完整性后合并证券。
6. 若 `ts_code` 重复、交易所/代码后缀不一致、任一组件为空或缺失，返回明确阻断原因。
7. 行情摄取只使用成功生成的 `SecurityMasterUniverse.securities` 作为范围门禁。

## 5. 时间与回测约束

- 首版真实冒烟使用当前已批准的两个官方快照，并记录各自 `collected_at`、`version` 和来源链接。
- 后续回测接口必须按目标交易日选择当时已经采集并可知的两个组件，不得读取未来快照。
- 本次实现为避免扩大范围，只为实时/当前摄取增加“双最新有效快照”集合；历史时点选择单独进入后续回测里程碑。

## 6. 失败与降级

以下情况必须阻断并记录可定位的错误码：

- `SECURITY_MASTER_SSE_UNAVAILABLE`
- `SECURITY_MASTER_SZSE_UNAVAILABLE`
- `SECURITY_MASTER_SOURCE_MISMATCH`
- `SECURITY_MASTER_DUPLICATE_TS_CODE`
- `SECURITY_MASTER_POLICY_DENIED`
- `SECURITY_MASTER_UNIVERSE_INVALID`

阻断时保留上一版报告并标记“本期未更新”，不得输出只覆盖一个交易所的新候选榜。

## 7. 本地文件与密钥

- `HENGCE_TUSHARE_TOKEN` 只写入被 Git 忽略的本地 `.env`，不得进入命令历史、日志、测试夹具、报告或提交。
- 官方下载的原文件进入本地数据目录并保留 SHA-256、下载页 URL、下载时间和转换说明。
- 标准化 CSV 分别保存为 SSE、SZSE 两份文件，不把两所记录手工拼成单一来源文件。

## 8. 验收测试

- 仅有 SSE 或仅有 SZSE 时，全市场集合不可用。
- 两个有效快照合并后覆盖 MAIN_SH、STAR、MAIN_SZ、CHINEXT。
- SSE 快照包含 `.SZ` 或 SZSE 快照包含 `.SH` 时，导入失败且不持久化。
- 任一来源策略被禁用、待复核或 URL 不匹配时，集合不可用并产生拒绝审计。
- 两个快照存在重复 `ts_code` 时阻断，不静默覆盖。
- 组件选择按 `source_id` 各取最新有效记录，不受另一个来源较晚采集时间挤占。
- `universe_hash` 对相同组件稳定，对任一组件版本或哈希变化敏感。
- 行情摄取接受合法沪深代码，拒绝集合外、北交所、B 股和港股代码。
- 日志、异常、CLI 输出和 Git 差异中不出现 Tushare Token。

## 9. 实施边界

本设计批准后，下一步编写小型实施计划并按测试驱动完成：

1. 来源一致性校验；
2. 双快照派生集合与错误码；
3. 行情摄取接入；
4. CLI/运行手册更新；
5. 全量测试和独立复审；
6. 在全新数据目录执行 2026-07-22 单日真实冒烟。
